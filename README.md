# 风来

免费的 Mac 温度监测与风扇控制工具。

[下载风来](https://github.com/zongkai16/fenglai/releases/latest) · [使用帮助](docs/privacy-and-support.md) · [反馈问题](https://github.com/zongkai16/fenglai/issues)

<img src="assets/widget.png" alt="风来桌面小组件" width="344">

## 功能

- 在菜单栏查看温度和风扇转速。
- 使用系统自动、目标温度、自定义转速或临时全速模式。
- 查看温度与转速趋势，添加桌面小组件。
- 支持登录启动和更新检查。

## 安装与使用

下载 `.pkg` 安装包，打开后按提示安装，再从“应用程序”中打开“风来”。首次安装遇到系统安全提示时，可查看[安装帮助](docs/privacy-and-support.md#安装提示)。

关闭窗口后，风来会继续在菜单栏运行。完全退出请点击菜单栏图标，选择“完全退出”。

需要 macOS 13 或更新版本；桌面小组件需要 macOS 14。
