# 数据、权限与故障排查

## 本地数据

风来在本机保存控制偏好、菜单栏显示偏好、温度与转速历史，以及供桌面小组件读取的快照。

| 数据 | 位置或用途 |
| --- | --- |
| 温度与转速历史 | `~/Library/Application Support/Fenglai/history/`，JSONL 格式，默认保留 30 天，最多 100 MiB |
| 小组件快照 | `~/Library/Application Support/Fenglai/widget/widget-snapshot.json` |
| 应用偏好 | macOS 为 `io.github.zongkai16.fenglai` 管理的偏好设置 |
| 控制服务配置与恢复记录 | `/Library/Application Support/Fenglai/`，由系统管理员权限保护 |

应用不提供账号、遥测或监测数据上传功能。默认在每次启动时连接 GitHub API 查询公开下载仓库的 Release 元数据；也可在设置中关闭“启动时检查更新”，保留手动检查。温度、转速、传感器列表和历史记录不会随此请求上传。GitHub 会接收正常网络请求所需的信息，例如来源 IP。

“登录时启动”由 macOS 的登录项服务管理。风来只在用户操作设置开关时申请登记或取消，设置页显示系统返回的实际授权状态。

## 控制权限

读取温度与调整风扇是两个独立步骤。风扇写入仅由风来的控制服务执行；服务校验调用用户和应用构建身份，并对转速范围、写入读回和恢复结果进行检查。

安装或更新控制服务可能需要 macOS 管理员身份验证。密码和 Touch ID 均由系统处理，风来不索取或保存密码。此版本的服务绑定安装时的本机用户及当前应用构建；其他用户或替换后的构建需要重新安装匹配的服务。

系统默认自动模式始终是建议的初始状态。退出应用、休眠或控制连接中断时，服务会尝试恢复自动；恢复尚未确认时会保留恢复记录并继续重试。请勿手动删除恢复记录来绕过提示。

## 常见情况

**没有风扇或无法切换模式**

部分 Mac 使用无风扇设计。未检测到风扇时，风来保留监测功能，并提示“未检测到风扇”。有风扇但控制失败时，以界面中的错误为准；能读取温度并不代表该机型支持写入转速。

**小组件与主窗口的读数不同**

主应用持续采样并写入本地快照，小组件由 macOS 的 WidgetKit 调度刷新。两者不会保证逐秒同步。主应用完全退出后，小组件会显示停止或过期状态；重新打开应用后等待系统刷新。

**目标温度降不下来**

温度目标是控制方向，实际结果受工作负载、环境和散热能力影响。“全速降温”表示散热需求已到最高；“已尽力”表示持续全速后仍高于目标。可降低负载或改用较易达到的目标。

**更新检查找不到版本**

请确认网络可访问 GitHub。更新信息来自公开下载仓库 `zongkai16/fenglai-releases`，无需 GitHub 账号或访问令牌。没有正式 Release、GitHub 限流或网络不可用时，手动检查后会显示相应状态。预发布版本不会作为正式更新提示。

**卸载**

先在设置中关闭“登录时启动”，再在菜单栏选择“完全退出”。运行随应用提供的卸载入口：

```sh
"/Applications/风来.app/Contents/Resources/uninstall-helper.command"
```

管理员身份验证由系统处理。卸载入口会确认恢复自动并移除控制服务；未确认恢复时，卸载会停止。完成后将应用移入废纸篓。个人历史和偏好默认保留；需要清除历史时可在退出后删除用户目录中的 `Fenglai` 数据文件夹。系统服务目录中的恢复记录应由卸载程序处理。

## 反馈问题

在[公开反馈区](https://github.com/zongkai16/fenglai-releases/issues)中提供风来版本、macOS 版本、对外机型名称、芯片类型和错误提示即可。反馈区对公众可见，请勿上传序列号、密码、访问令牌或未经检查的整机日志。
