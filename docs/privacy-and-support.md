# 数据与帮助

**数据保存在哪里？**

温度、转速历史和个人偏好都保存在本机。历史默认保留 30 天，桌面小组件也读取本机数据。风来不要求注册账号。

**什么时候会联网？**

风来默认在每次启动时连接 GitHub 查询新版本，点击“检查更新”也会联网。可在设置中关闭“启动时检查更新”，之后按需手动检查。检查更新不会上传温度、转速、传感器列表或历史记录；GitHub 可能收到来源 IP 等网络连接信息。发现新版本后，由你决定是否下载和安装。

**为什么需要管理员确认？**

安装、更新或移除风扇控制服务时，macOS 可能要求管理员密码或 Touch ID。身份验证由系统处理，风来不收集或保存密码。

## 安装提示

本版尚未通过 Apple 公证，首次安装或打开时，macOS 可能提示“无法验证开发者”。确认安装包来自风来的下载页后，可在“系统设置 → 隐私与安全性”中使用允许打开的入口，再按系统提示确认。

**哪些 Mac 可以使用？**

需要 macOS 13 或更新版本。安装包同时包含 Apple 芯片和 Intel 架构。目前已在 MacBook Pro 14 英寸（2021，M1 Pro）上实测；Intel 及其他机型的温度读取、风扇控制能力尚未确认。

## 使用帮助

**小组件刷新**

小组件由 macOS 安排刷新，读数可能稍晚于主窗口。主应用完全退出后，小组件会显示停止或过期状态。

**目标温度**

实际温度受工作负载、环境温度和散热能力影响。持续高于目标时，可先减少正在运行的重任务。

## 卸载

先在设置中关闭“登录时启动”，再从菜单栏选择“完全退出”。打开“终端”，粘贴并运行下面一行：

```sh
"/Applications/风来.app/Contents/Resources/uninstall-helper.command"
```

按系统提示完成管理员验证。卸载工具会先确认风扇恢复系统自动控制，再移除控制服务；若恢复未完成，会停止卸载。完成后，将“应用程序”中的风来移入废纸篓。个人历史和偏好默认保留。
